# 集客の仕組み（Claude 運用マニュアル）

このフォルダは、Claude が毎週コラムを作り、LinkedIn と連動して集客するための作業手順です。
**砂川さんが読む必要はありません。** Claude はここを読んでから作業します。

## 毎週の流れ（毎週水曜 自動開始）
記事の公開先は **会社のホームページ（skyupinc.com のWordPress「ニュース・コラム」）**。
WordPress へは今のところ砂川さんが手で貼り付ける（Basic認証のため API 投稿は不可。制作会社に相談中）。

1. `editorial-guide.md`・`topics.md`・`linkedin-template.md` と、砂川さんの発信ルール文書（Claude Docs）を読む
2. 原稿置き場の Claude Docs「スカイアップ コラム原稿」 https://claude.ai/artifact/31KVKYndFyKn4M95YcZWHw の「連載計画と手順」タブで、次に書く回を確認する（連載の順番を優先。時事ネタは中身に絡める）
3. 直近1〜2週間のニュースを WebSearch で調べる（一次情報・公的統計を優先。開けなかった出典はそう伝える）
4. 同じドキュメントに新しいタブ「第N回 ○○」を追加し、原稿を書く
   - 1行目にタイトル、2行目に「カテゴリー：○○／タグ：○○、○○」（カテゴリーは1つ、タグは2〜4個。タグは「連載計画と手順」タブの表から選ぶ）、以降が本文
   - 原稿の最後に「WordPress貼り付け用HTML」をコードブロックで付ける。HTMLは原稿を簡単なMarkdownで書き `python3 content-ops/to_html.py 原稿.md` で作る（書き方はスクリプト冒頭参照）
   - 過去のLinkedIn投稿の全文は `content-ops/source/linkedin_archive.md`。金曜の回はここから「採用の目線」で作り直す
   - 最後に LP への案内（無料相談 or パートナー応募）。リンクには ?utm_source=corporate&utm_medium=referral&utm_campaign=column を付ける
   - 太字の `**` は、閉じる側の直後が「の」などの文字だと崩れる。崩れたら太字をやめる
5. LinkedIn 投稿文（本文＋最初のコメント）を作り、チャットで砂川さんに送る。共感型投稿用の質問も2つ送る
6. 砂川さんが WordPress に貼って公開 → 公開URLをもらったら、LinkedIn 投稿文のリンクを確定する
7. 「連載計画と手順」タブの該当回に公開日をメモする

※ LP 側の `column*.html` と `content-ops/articles/`・`build.py` は、記事の重複を避けるため使わない（保管用）。

## 毎月の流れ（毎月1日 自動開始）
1. Gmail の過去のやりとりから、案内メールを送る候補（面識のある取引先・パートナー候補）を最大10件選ぶ
2. 新しく公開したコラムやLPを紹介する文面を、相手ごとに作る
3. **Gmail に下書きとして保存するだけ**（送信は絶対にしない）
4. 砂川さんに「候補一覧と下書き件数」を報告し、最終確認・送信をお願いする

## 参考にする情報（毎回確認）
- OneDrive の「LinkedIn」や「コラム」を含むフォルダ・ファイル（砂川さんの過去投稿・メモ）を sharepoint_search で探して読む
- 砂川さんから共有された LinkedIn 投稿の URL や本文（このリポジトリの `content-ops/voice-notes.md` に要点をメモしておく）

## 守ること
- 記事は必ず砂川さんの OK のあとで公開する
- メールは送信しない（下書きまで）
- 取引先の社名・個人名・報酬額は書かない
- 数字には必ず出典を付ける。出典が見つからない数字は書かない
