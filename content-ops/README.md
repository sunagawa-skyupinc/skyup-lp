# 集客の仕組み（Claude 運用マニュアル）

このフォルダは、Claude が毎週コラムを作り、LinkedIn と連動して集客するための作業手順です。
**砂川さんが読む必要はありません。** Claude はここを読んでから作業します。

## 毎週の流れ（毎週水曜 自動開始）
1. `editorial-guide.md` と `topics.md` を読む
2. 直近1〜2週間のニュースを WebSearch で調べ、テーマに合う話題を1つ選ぶ（一次情報・公的統計を優先）
3. `articles/<slug>.json` を `"status": "draft"` で作成
   - slug 形式：`YYYY-MM-英語の短い説明`
4. 一時的に `"published"` にして `python3 content-ops/build.py` → スクリーンショットで崩れを確認 → `draft` に戻して再ビルド
5. LinkedIn 投稿文を `linkedin-template.md` に沿って作り、JSON の `linkedin_post` に入れる
6. 砂川さんに「記事のスクリーンショット」「要約」「LinkedIn 投稿文」を送って確認を依頼
7. 「OK」が出たら `published` にしてビルド → コミット → PR 作成 → main にマージ（＝公開）
8. `topics.md` の該当テーマに公開日を記入

## 毎月の流れ（毎月1日 自動開始）
1. Gmail の過去のやりとりから、案内メールを送る候補（面識のある取引先・パートナー候補）を最大10件選ぶ
2. 新しく公開したコラムやLPを紹介する文面を、相手ごとに作る
3. **Gmail に下書きとして保存するだけ**（送信は絶対にしない）
4. 砂川さんに「候補一覧と下書き件数」を報告し、最終確認・送信をお願いする

## 参考にする情報（毎回確認）
- OneDrive の「LinkedIn」や「コラム」を含むフォルダ・ファイル（砂川さんの過去投稿・メモ）を sharepoint_search で探して読む
- 砂川さんから共有された LinkedIn 投稿の URL や本文（このリポジトリの `content-ops/voice-notes.md` に要点をメモしておく）

## 守ること
- 記事は必ず砂川さんの OK のあとで公開する
- メールは送信しない（下書きまで）
- 取引先の社名・個人名・報酬額は書かない
- 数字には必ず出典を付ける。出典が見つからない数字は書かない
