# LinkedIn 投稿文の作り方（砂川さんが自分のアカウントで投稿）

**最優先：砂川さんの発信ルール文書を毎回読むこと。**
「スカイアップ 発信運用プロンプト（LinkedIn／コミュニティ）」 https://claude.ai/artifact/3efTdAV5gQWZBHAYqA9Vdv
（Claude Docs のドキュメント。docs ツールで read する。文体・禁止表現・論調のバランス・過去の発信テーマはそちらが正）

## 要点（詳細は上の文書）
- 目指すのは「本人がスマホで思ったことをそのまま書いた文章」。きれいに整えすぎない
- 改行は2〜3文ごと。短文の連打、三段並列、対比構文（〜ではなく〜なのです）、名言っぽい締めは使わない
- 「だからこそ」「そして」「つまり」「本当の意味で」「大切なのは」、抽象語（人生・未来・可能性・挑戦・希望）は使わない
- 具体的な出来事と数字で書く。**砂川さんが話していないエピソードは作らない**（必要なら本人に質問する）
- 最後は自分の考え → 短い問いかけで終える
- 絵文字なし、ハッシュタグ4〜5個
- **URLは本文に入れず、投稿後の最初のコメントに貼る**（外部リンクはリーチが下がる）
- 投稿の時間帯：平日 8〜9時台 か 12時台
